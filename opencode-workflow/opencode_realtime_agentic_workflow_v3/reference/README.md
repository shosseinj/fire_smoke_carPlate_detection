# Previous option catalog source

`app_names_and_urls.xlsx` is the spreadsheet supplied for this workflow.

During installation it is copied to:

`.agentic/migration/source/previous-project-options.xlsx`

It is also normalized into:

`.agentic/migration/legacy-endpoint-catalog.json`

The spreadsheet is a catalog or partial specification. It is not a previous source repository and does not prove exact old behavior.
